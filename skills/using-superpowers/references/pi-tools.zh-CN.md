# Pi 工具映射

技能以动作来表述（"派发子代理"、"创建待办"、"读取文件"）。在 Pi 上，这些动作对应为下列工具。

| 技能请求的动作 | Pi 对应工具 |
| --- | --- |
| 派发子代理（`Subagent (general-purpose):` 模板） | 如果可用，使用已安装的子代理工具，例如 `pi-subagents` 提供的 `subagent` |
| 任务跟踪（"创建待办"、"标记完成"） | 如果可用，使用已安装的待办/任务工具，否则在计划或 `TODO.md` 中跟踪任务 |

## 子代理

Pi 核心不内置标准的子代理工具。`pi-subagents` 包是一个强大的可选伴侣，提供 `subagent` 工具，支持单代理、链式、并行、异步、分叉上下文以及恢复/状态等工作流。如果没有可用的子代理工具，不要捏造 `Task` 调用；在当前会话中顺序执行，或说明可选的子代理能力尚未安装。

## 任务列表

Pi 核心不内置标准的任务列表工具。如果安装了待办/任务扩展，请使用其文档化的工具。否则，请使用 Superpowers 计划文件、Markdown 清单或仓库内的 `TODO.md` 进行任务跟踪。较旧的 Superpowers 文档可能会提到 `TodoWrite`；请将其视为上述的任务跟踪动作。
